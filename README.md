# رحلة الحروف مع المعلم سعد — الإصدار 3.0

منصة عربية تعليمية ثابتة تعمل على GitHub Pages، باتجاه كامل من اليمين إلى اليسار.

## الميزات
- الهوية البصرية المعتمدة تظهر مرة واحدة في الأعلى.
- محرك درس واحد للحروف الستة: م، ب، ل، د، ن، ر.
- سبع مراحل لكل حرف: المقدمة، القصة، النشاط، اللعبة، الصفحات، التقويم، الوسام.
- حفظ تقدم الطالب والنجوم والأوسمة داخل المتصفح.
- استوديو تسجيل مدمج، ولوحة معلم محلية، ومدير ملفات صوت.
- ملفات بيانات JSON منفصلة لكل حرف، مع نسخة مدمجة تضمن عمل الموقع عند فتح `index.html` محليًا.
- توافق مع الكمبيوتر والجوال والآيباد والأجهزة اللوحية.

## مسارات الصوت
ضع ملفات WEBM بالأسماء التالية داخل مجلد كل حرف:
- `intro.webm`
- `story.webm`
- `success.webm`

مثال: `assets/audio/meem/intro.webm`

## النشر
انسخ محتويات هذا المجلد إلى جذر مستودع GitHub، ثم Commit وPush.

# رحلة الحروف مع المعلم سعد — النسخة الكاملة 3.0

هذه حزمة موقع كاملة وجاهزة للنشر على GitHub Pages.

## النشر

ارفع **محتويات هذا المجلد كلها** إلى جذر مستودع GitHub، بحيث يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع.

## إضافة الصوت

لا تحتاج إلى تعديل `index.html` أو أي كود. أضف ملفات MP3 فقط بالأسماء والمسارات المحددة في `دليل_إضافة_الصوت.txt`.

مثال صوت مقدمة حرف الميم:

`assets/audio/meem/intro.mp3`

بعد رفع الملف إلى GitHub، انتظر اكتمال النشر ثم افتح الموقع وحدّث الصفحة تحديثاً قوياً.

## ملفات مهمة

- `index.html`: الموقع كامل، بما فيه التصميم والصور والبرمجة.
- `audio-manifest.json`: خريطة التسجيلات الصوتية.
- `audio-manager.html`: صفحة لفحص التسجيلات الموجودة والمفقودة.
- `assets/audio/`: مكان ملفات MP3.

# رحلة الحروف مع المعلم سعد - الإصدار الذهبي 1.0

هذه هي النسخة المرجعية المستقرة والجاهزة للنشر على GitHub Pages.

## الملفات الرئيسية

- `index.html`: الموقع التعليمي.
- `studio.html`: استوديو التسجيل الصوتي.
- `audio-manager.html`: صفحة فحص وجود التسجيلات.
- `audio-manifest.json`: خريطة مسارات الصوت.
- `docs/دليل_الاستخدام.pdf`: دليل الرفع والاستخدام.
- `data/letters.json`: تعريف الحروف.
- `data/settings.json`: إعدادات المشروع المرجعية.

## إضافة تسجيل الترحيب

انسخ ملفك باسم:

`welcome.webm`

إلى المسار:

`assets/audio/welcome.webm`

ثم ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، بحيث يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع.

## روابط الموقع بعد النشر

- الصفحة الرئيسية: `/index.html`
- الاستوديو: `/studio.html`
- فحص الصوت: `/audio-manager.html`

## قاعدة التحديثات المستقبلية

لا تغيّر أسماء المجلدات أو مسارات الصوت. تكون الإصدارات التالية 1.1 و1.2 وما بعدها مع الحفاظ على هذه البنية.

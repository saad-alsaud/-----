# رحلة الحروف مع المعلم سعد — الإصدار الرسمي 2.0

نسخة إنتاجية متجاوبة واتجاهها من اليمين إلى اليسار، وتضم الحروف: م، ب، ل، د، ن، ر.

## النشر
انسخ محتويات هذا المجلد إلى جذر مستودع SAADALSAUD، ثم نفّذ Commit وPush عبر GitHub Desktop.

## الصوت
- الترحيب: `assets/audio/welcome.webm`
- مقدمة الميم: `assets/audio/meem/intro.webm`
- القصة: `story.webm`
- الإنجاز: `success.webm`

لا تحذف مجلد `.git` في مستودعك المحلي.

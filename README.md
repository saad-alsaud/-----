# رحلة الحروف مع المعلم سعد — الإصدار الرسمي 2.0

نسخة نشر نهائية مبنية على الإصدار الذهبي، وتشمل:

- هوية بصرية ثابتة ومتجاوبة بثلاثة مقاسات.
- اتجاه عربي كامل من اليمين إلى اليسار.
- الشخصيات الرسمية: مشعل، فاطمة، سعد، مريم، فوّاز، نورة، ياسر.
- ستة دروس: الميم، الباء، اللام، الدال، النون، الراء.
- مقدمة وقصة ونشاط ورسالة إنجاز لكل حرف.
- استوديو تسجيل ومسارات صوت منظمة.
- حفظ تقدم الطفل محليًا.
- توافق مع GitHub Pages، الكمبيوتر، الآيباد، والأجهزة المحمولة.

## ملفات التسجيل

ضع ملفات الصوت بصيغة WebM داخل:

`assets/audio/<slug>/intro.webm`
`assets/audio/<slug>/story.webm`
`assets/audio/<slug>/success.webm`

مثال حرف الميم:

`assets/audio/meem/intro.webm`

## النشر

انسخ محتويات هذه الحزمة إلى جذر المستودع، ثم نفّذ Commit وPush origin.

رحلة الحروف مع المعلم سعد

دليل الإصدار الذهبي 1.0
قاعدة مهمة: ارفع محتويات مجلد الحزمة إلى جذر المستودع، بحيث يظهر ملف index.html مباشرة في الصفحة الرئيسية للمستودع.

1. تجهيز ملف الترحيب

قبل الرفع، انسخ تسجيل الترحيب باسم welcome.webm إلى assets/audio/. يصبح المسار الكامل assets/audio/welcome.webm.

2. استبدال الملفات في GitHub

  1. نزّل نسخة احتياطية من المشروع القديم.
  2. احذف الملفات القديمة من المستودع.
  3. فك ضغط الحزمة الذهبية.
  4. ارفع جميع الملفات والمجلدات الموجودة داخل الحزمة.
  5. اضغط Commit changes.

3. الصفحات الرئيسية

  • index.html: الموقع التعليمي.
  • studio.html: تسجيل المقاطع وتنزيلها.
  • audio-manager.html: فحص الملفات الصوتية التي وصلت إلى الموقع.

4. مسارات تسجيلات الحروف

لكل حرف ثلاثة ملفات: intro.webm وstory.webm وsuccess.webm. توضع داخل مجلد الحرف: meem أو baa أو laam أو daal أو noon أو raa.

5. التحقق بعد النشر

  1. افتح الصفحة الرئيسية وتأكد من ظهور الواجهة.
  2. افتح studio.html وتأكد من السماح للمتصفح بالميكروفون.
  3. افتح audio-manager.html وتحقق من حالة كل تسجيل.
  4. جرّب الصوت من الصفحة الرئيسية.

6. الصيانة المستقبلية

لا تغيّر أسماء الملفات أو المجلدات. ستُبنى التحديثات المقبلة على البنية نفسها بأرقام 1.1 و1.2 وما بعدها.
